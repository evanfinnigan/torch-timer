# torch-timer
A basic torch timer for Shadowdark RPG

[Try it here](https://evanfinnigan.github.io/torch-timer/)

<img width="854" height="1059" alt="image" src="https://github.com/user-attachments/assets/f4637614-9d85-4402-971e-df918d197b4c" />

## Features
- 60 minute timer with countdown
- Torch image fades as the timer gets closer to 0
- Light a new torch with 1 click
- Pause / unpause
